BHM-style Chinese/Cantonese Dictionary for openutau_ver1.0
by Aldof
This dictionary is based on the BHM scheme, allowing BHM-style Chinese/Cantonese voicebanks in OpenUtau to automatically split sounds by directly inputting Chinese characters, Pinyin, or Jyutping.
This YAML file references the following repository: https://github.com/stakira/OpenUtau/pull/776

Usage:

1. Copy and paste the zhcvv.yaml file from the extracted folder into the directory of the BHM-style Chinese/Cantonese voicebank in OpenUtau (the BHM_Chinese folder contains the Chinese dictionary, and the BHM_Cantonese folder contains the Cantonese dictionary). For example, paste zhcvv.yaml into E:\OpenUtau\Singers\BHMChinese_Singer.

2. Select the ZH CVV (October-style Phoneme Expansion) phonemizer in OpenUtau.

3. Refresh the singer, and directly input Chinese (characters or Pinyin) or Jyutping (currently only Jyutping is supported) in the editing interface to automatically split sounds.

BHM式中式・広東語辞書 for openutau_ver1.0
by Aldof
この辞書はBHM方式に基づいて作成され、BHM式中式・広東語音源がOpenUtauで直接中国語（漢字または拼音）または粤拼（広東語拼音）を入力することで自動的に音分割を実現できます。
このYAMLファイルは以下のリポジトリを参考にしています：https://github.com/stakira/OpenUtau/pull/776

使用方法：

1、解凍したフォルダ内のzhcvv.yamlを、OpenUtauでBHM式中式・広東語音源を使用するフォルダにコピーして貼り付けます（BHM_Chineseフォルダには中国語辞書、BHM_Cantoneseフォルダには広東語辞書が含まれています）。例：zhcvv.yamlをE:\OpenUtau\Singers\BHMChinese_Singerに貼り付けます。

2、OpenUtauでZH CVV（October式音素拡張）フォネマイザーを選択します。

3、歌手をリフレッシュし、編集画面で直接中国語（漢字または拼音）または粤拼（現在は粤拼のみ対応）を入力すると、自動的に音分割されます。
